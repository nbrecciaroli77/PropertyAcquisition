# Initial private prototype acceptance checklist

## Blocking gates

- [ ] No cross-workspace data access through API, storage, deep links, jobs, exports or caches.
- [ ] No accidental agent send, booking or offer pathway.
- [ ] Migrations apply from empty database and rollback/reset is documented.
- [ ] Replaying an intake event creates no duplicate property, notification or digest effect.
- [ ] Known hard failure cannot be overridden by preference fit.
- [ ] Unknown remains distinct from zero, false, pass and fail.
- [ ] Fit and evidence coverage are separate and reproducible.
- [ ] Unit suffixes remain distinct and false merge can be undone.
- [ ] Secrets are absent from prompts, repository, fixtures and logs.

## Core journey

- [ ] Signup, verification state, login, reset and logout work.
- [ ] Google identity does not imply Gmail permission.
- [ ] Buying journey and versioned brief work on desktop and phone.
- [ ] Manual, pasted-text and CSV fixture intake work without scraping.
- [ ] Today, Discover, Pipeline, detail, evidence, compare and shortlist have functional empty/error/loading states.
- [ ] Notes, tasks, ICS reminder and UNSENT drafts behave truthfully.
- [ ] Source cards distinguish configuration from confirmed receipt.
- [ ] Export and deletion operate within documented private-prototype limits.

## Digest and responsive design

- [ ] Digest sends at most five candidates without padding.
- [ ] Quiet-day and Monday-recap variants render.
- [ ] Property image is optional, attributable and address-matched.
- [ ] Site plans and photographs have correct labels.
- [ ] Layout stacks at phone width with no horizontal overflow.
- [ ] Images-disabled email remains readable.
- [ ] Deadline timezone and date-only semantics are correct.
- [ ] No page overflow at 320 CSS pixels; keyboard and visible focus pass.

## Handover

- [ ] Private GitHub repository contains source and milestone commits.
- [ ] README covers local setup, environment variables, seed/reset and tests.
- [ ] Built/Deferred/Blocked traceability is current.
- [ ] Critical/High defects are zero before private preview deployment.
- [ ] Live Perth Google Drive, Gmail, portals and ChatGPT tasks remain untouched.
